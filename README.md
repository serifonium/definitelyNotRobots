## CAB302 Group Project

Meal Creator:

- Generates Meals based on user input of ingredients (what’s in my pantry?)  
- Identifies ingredients based on image input of pantry/fridge and generates a recipe  
- Adaptable meal settings based on health issues/dietary requirements  
- Set-by-step recipes in easily readable user interface  
- Generates recipes based on images of a dish  
- Adaptable recipes based on user taste preferences  
- Adaptable fitness or calorie goals  
- Create a grocery list based on ingredients already owned vs. need to buy  
- Find nearby specials of ingredients at supermarkets  
- Save/record generated meals  
- Recipe rating to alter future recommendations
